# Flask + MySQL ToDo アプリケーション

認証機能付きのToDoリスト管理アプリケーション

## 技術スタック

-Python 3.11
-Flask 3.0
-SQLAlchemy 2.0
-MySQL 8.0
-Docker

## 機能

-ユーザー登録・ログイン
-ToDo CRUD操作
-完了/未完了管理

## 開発コマンド

    # コンテナ起動
    make up

    # ログ確認
    make logs

    # シェルに入る
    make shell

    # データベースシェル
    make db-shell

    # テスト実行
    make test

    # カバレッジ測定
    make test-cov

    # コードフォーマット
    make format

    # リンター実行
    make lint

    # データベースリセット
    make reset-db

    # コンテナ停止
    make down
